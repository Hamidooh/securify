# Security Policy

## Reporting Security Vulnerabilities

If you discover a security vulnerability in Securify, please report it privately:

- **Report Channel**: Please report vulnerabilities privately via [GitHub Security Advisories](https://github.com/Hamidooh/securify/security/advisories) or directly to maintainer **[@Hamidooh](https://github.com/Hamidooh)**.
- **Response Time**: We respond within 24-48 hours with verification and fix timelines.
- Please avoid opening public issues for unpatched vulnerabilities.
